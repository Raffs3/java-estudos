# Java Estudos - Fundamentos e Tipos Primitivos

Este repositório reúne meus estudos iniciais em Java, utilizando o JDK 21. O foco é praticar os fundamentos da linguagem, compreender o funcionamento dos tipos de dados primitivos e desenvolver boas práticas de organização e versionamento com Git.

Os exercícios foram desenvolvidos para aplicar os conceitos estudados em diferentes situações práticas, reforçando a lógica de programação e a familiaridade com a linguagem.

## 📂 Exercícios Desenvolvidos

O projeto contém classes com exercícios práticos envolvendo manipulação de dados, operações matemáticas, cálculos e lógica de programação:

- **CadastroDeProdutos:** Simulação de cadastro e controle de produtos utilizando `String`, `long`, `double`, `int`, `boolean` e `char`.
- **CalculadoraDeDespesas:** Controle de despesas mensais e cálculo de saldo restante utilizando `double`.
- **CalculadoraDeTroco:** Operações matemáticas envolvendo cálculo de troco e divisão de valores em parcelas.
- **FichaDeAtleta:** Registro de dados de atletas e cálculo de Índice de Massa Corporal (IMC).
- **FichaDePersonagem:** Modelagem de atributos de personagens de RPG utilizando diferentes tipos de dados.
- **Jogador:** Registro de informações e estatísticas de jogadores.
- **MetricasDeVideo:** Simulação de métricas de visualizações, curtidas e engajamento.
- **RegistroDeCorrida:** Cálculo de distância, tempo e ritmo (pace) de corrida.
- **RegistroPopulacional:** Manipulação de dados populacionais com diferentes escalas numéricas utilizando `int` e `long`.
- **SensorDeTemperatura:** Conversão de temperaturas utilizando números de ponto flutuante (`float` e `double`).
- **StatusDoInimigo:** Modelagem de atributos de inimigos de jogos e cálculo de pontos de vida.
- **VariaveisExemplos:** Exercícios iniciais e anotações sobre variáveis, tipos primitivos e `String`.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 21 - Eclipse Temurin)
- **IDE:** JetBrains IntelliJ IDEA
- **Controle de versão:** Git e GitHub

## 🎯 Objetivo

Consolidar os conhecimentos fundamentais de Java por meio da prática, desenvolvendo gradualmente a lógica de programação e construindo uma base para estudos futuros em programação orientada a objetos e desenvolvimento de aplicações.
