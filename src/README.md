# Java Estudos - Fundamentos e Tipos Primitivos

Este repositório é o início da minha jornada de aprendizado em Java, focado em consolidar a sintaxe da linguagem (JDK 21), a manipulação correta de tipos de dados primitivos e as boas práticas de versionamento com Git.

## 📂 Exercícios Desenvolvidos
O projeto conta com diversas classes práticas aplicadas a cenários reais, controle financeiro, métricas e lógica de jogos:

- **CadastroDeProdutos:** Simulação de inventário utilizando `String`, `long`, `double`, `int`, `boolean` e `char`.
- **CalculadoraDeDespesas:** Gestão de contas mensais e cálculo de sobra salarial com decimais (`double`).
- **CalculadoraDeTroco:** Operações matemáticas para cálculo de troco em dinheiro e divisão de parcelas.
- **FichaDeAtleta:** Registo de dados de desportistas, incluindo o cálculo dinâmico de IMC.
- **FichaDePersonagem:** Estruturação de atributos de RPG com múltiplos tipos primitivos.
- **Jogador:** Registo de perfil e estatísticas de jogadores.
- **MetricasDeVideo:** Painel simulado de visualizações, likes e engajamento.
- **RegistroDeCorrida:** Medição de distância, tempo e cálculo de pace em percursos.
- **RegistroPopulacional:** Exploração de escalas numéricas de cidades até populações globais (`int` e `long`).
- **SensorDeTemperatura:** Conversão de unidades térmicas utilizando números de ponto flutuante (`float`/`double`).
- **StatusDoInimigo:** Modelagem de atributos de chefes de jogos e cálculo de diferença de vida.
- **VariaveisExemplos:** Classe inicial de testes e anotações sobre os tipos primitivos e `String`.

## 🛠️ Tecnologias e Ferramentas
- **Linguagem:** Java (JDK 21 - Eclipse Temurin)
- **IDE:** JetBrains IntelliJ IDEA
- **Controle de Versão:** Git & GitHub
